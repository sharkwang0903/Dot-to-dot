# DOT TO DOT — 像素寶石連連看

純 HTML、CSS、JavaScript 的十六關連連看，共 48 顆通關星星。沒有框架、套件、建置步驟、外部字型、外部圖片或網路 API。

## 如何遊玩

直接用 Chrome、Edge、Firefox 或 Safari 開啟（或雙擊）`index.html`。請保留 `styles.css` 與 `js` 資料夾的相對位置。

首頁 → 開始遊戲 → 關卡選擇 → 配對消除 → 通關結算。第 1 關預設解鎖，通關後解鎖下一關。已解鎖關卡可以自由重玩。

遊戲本身不需要 Node.js，也不需要啟動伺服器。

## 遊戲規則

- 點選兩顆相同顏色的寶石，以水平／垂直連線連接，最多轉彎兩次，可以繞棋盤外圍。
- 連線不能穿過其他寶石或牆壁；牆壁不能消除。
- 寶石集合共十五種：紅、藍、黃、綠、黑、白、紫、橘、青、玫紅、萊姆、靛、琥珀、孔雀、珊瑚。每種另有專屬像素符號，輔助辨識相近顏色。
- 每關從該關已開放的集合中隨機抽出固定數量的顏色，再隨機配置成對寶石。第 1～8 關使用原本九種集合；第 9～14 關每關加入一種新寶石，第 14 關起可抽選集合完整擴充到十五種。每關格子、空洞與牆壁位置固定。
- 第 9～16 關包含雙島、四個分離牌區、中央長牆、錯位牌區等版型。分區間的空白可以通行，牆壁仍必須繞開；所有版型都檢查了任意最後兩顆的可連線性。
- 剩餘牌面沒有合法配對時，自動洗牌，只交換仍在場上的寶石，不改變空格、牆壁或各色數量。洗牌動畫暫停關卡與連擊計時。
- 相鄰兩次成功消除間隔不超過 2 秒即累積連擊。每五次連擊，額外隨機消除一組同色寶石，忽略路徑限制。獎勵本身不累積連擊；下一次從 1/5 開始。
- 倒數結束前清空寶石即通關；倒數歸零即失敗。最後只剩牆壁也算通關。
- 不同關卡各自使用完整限時、從零計分。

### 星級

以通關當下「剩餘毫秒 ÷ 該關總限時」判定：

| 剩餘比例 | 評價 |
| --- | --- |
| > 50% | 三星 |
| 25%～50%，包含端點 | 二星 |
| > 0%、< 25% | 一星 |
| 0% | 失敗 |

時間條有 25% 與 50% 刻線，並同步顯示當前可取得的星級。畫面秒數無條件進位顯示，實際星級用精確時間判斷。

### 分數

- 每組基本 100 分。
- 同一輪連擊第 2、3、4、5 組，分別額外加 25、50、75、100 分。
- 獎勵消除的一組另加 100 分。
- 通關時，每剩餘 1 秒（無條件進位）加 10 分。
- 例：連消五組且成功獎勵一組，共得 `100 + 125 + 150 + 175 + 200 + 100 = 850` 分。
- 提示不扣分，每 5 秒可以使用一次。

## 操作與紀錄

- 滑鼠或觸控點選寶石；再次點選已選寶石可取消。
- Tab 移動焦點，方向鍵在棋盤內移動，Enter／空白鍵選取，Esc 暫停／繼續。
- 暫停會凍結倒數與連擊，並隱藏棋盤。切換分頁或視窗失去焦點時也會自動暫停。
- 右上角可切換音效、開啟說明；音效使用瀏覽器 Web Audio 合成。
- 各關獨立保存最佳星數、最高分與最快通關時間，三個最佳值可以來自不同次挑戰。
- 舊版已通關第 8 關的紀錄，更新後自動解鎖第 9 關；已解鎖第 8 關但尚未通關者，仍需先通過第 8 關。原有分數、星級與音效設定會保留。
- 紀錄使用此瀏覽器的 `localStorage`，不會跨裝置或瀏覽器同步。清除網站資料、無痕模式，或更換檔案位置／開啟來源，可能影響紀錄。若瀏覽器拒絕儲存，遊戲仍可玩，並會顯示提示。

## 檔案分工

| 檔案 | 負責內容 |
| --- | --- |
| `index.html` | 首頁、關卡選單、遊戲畫面、時間條、彈窗容器與共用圖示；依順序載入六個 JS 檔。 |
| `styles.css` | 像素風外觀、配色、桌面／手機排版、棋盤、按鈕、動畫與減少動態效果設定。 |
| `js/levels.js` | 十五種寶石的顏色／符號，以及十六關的固定版型、色數、可抽選集合大小、限時。 |
| `js/engine.js` | 純規則：隨機牌面、最多兩轉的路徑搜尋、可用配對、洗牌保底、隨機獎勵配對、星級與連擊判斷。 |
| `js/storage.js` | 讀寫本機紀錄、解鎖進度、音效偏好，以及無法儲存時的備援。 |
| `js/audio.js` | 用原生 Web Audio 產生點選、消除、獎勵、洗牌、通關與失敗音效。 |
| `js/ui.js` | 繪製像素寶石／標題、關卡卡片、棋盤、連線動畫、提示、星級與彈窗。 |
| `js/game.js` | 統整遊戲狀態：開始、點選、倒數、連擊獎勵、自動洗牌、暫停、提示、結算、重玩與導覽。 |
| `tests/rules.test.js` | 可選規則測試：獨立搜尋對照、各關隨機模擬、牆壁／洗牌／色數／星級／紀錄驗證。 |
| `tests/timing.test.js` | 可選時序測試：控制虛擬時鐘，驗證暫停、超時、連擊間隔、結算、切關與延遲清理。 |
| `tests/storage.test.js` | 驗證舊八關存檔升級、第 9～16 關解鎖、紀錄保存與重新載入。 |
| `preview/home.png`、`preview/game.png` | 實際瀏覽器畫面截圖，僅供預覽，遊戲不會載入。 |
| `preview/level-16.png` | 十六關擴充版的最終關卡畫面；獨立測試存檔，不影響玩家紀錄。 |
| `README.md` | 啟動方法、規則、關卡數據、檔案分工與修改指引。 |

使用一般 `defer` 腳本而非 ES modules，讓直接以 `file://` 開啟也能載入拆分的 JS。共用資料放在 `window.DotGame`，各檔案內部以函式封裝，避免互相污染。

## 想調整時改哪裡

- 改關卡時間、色數、牆壁位置：`js/levels.js`。`colors` 控制當場顏色種類，`poolSize` 控制可抽選集合大小（取 `GEMS` 前幾種）；未設定 `poolSize` 時預設為九種。
- 版型字元 `X` 表示寶石、`#` 表示牆壁、`.` 表示空白。每列必須等寬，寶石總數必須是偶數；每種顏色至少需要一組。
- 改寶石顏色：`js/levels.js` 的 `GEMS`；改形狀和符號：`js/ui.js` 的 `gem()`。
- 改分數公式：`js/game.js` 的 `choose()` 與 `finish()`，並同步更新遊戲內說明。
- 改整體視覺：`styles.css` 的 `:root` 色票與對應元件。
- 新增或改變牆壁版型後，建議執行規則測試，避免無法靠洗牌解決的尾盤。

## 已完成的驗證

使用 Node.js 內建功能即可選擇性執行，不需安裝任何套件：

```text
node tests/rules.test.js
node tests/timing.test.js
node tests/storage.test.js
```

規則測試涵蓋 700 個隨機棋盤與獨立方向搜尋結果比對、十六關各 35 局（共 560 局）、每個版型的任意最後兩顆位置、洗牌保留位置與數量、強制洗牌保底、逐關集合限制、連擊／星級精確邊界，以及紀錄不被較差成績覆蓋。

流程測試涵蓋暫停 90 秒、連消五組額外消除、2 秒連擊逾時、倒數歸零失敗、失敗後停止接受配對、過關解鎖、獨立關卡計分、分頁隱藏暫停及離開後的計時清理。

擴充版另外以虛擬時鐘跑完第 8～16 關的完整遊戲控制流程，檢查下一關按鈕與最終結算；儲存測試涵蓋舊存檔自動解鎖第 9 關，以及第 16 關紀錄重新載入。

另外已在內建 Chromium 瀏覽器實際遊玩第 1～4 關，檢查首頁、解鎖、牆壁、連擊、結算、重玩、提示、暫停與離開確認；在桌面與 390px 手機寬度檢查版面。未逐一實機測試所有瀏覽器。

十六關擴充版已使用獨立測試存檔在瀏覽器實際打通第 16 關，確認新寶石圖形、104 顆牌面、15 色圖例與全關完成結算；測試不會寫入玩家原有存檔。
